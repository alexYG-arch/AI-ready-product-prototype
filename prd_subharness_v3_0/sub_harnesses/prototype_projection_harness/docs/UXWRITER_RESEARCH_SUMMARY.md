# UX Writer Stage Research Summary

The v1.2 UX writer rules are based on public UX writing, content design, accessibility, and platform style guidance.

## Adopted principles

- UX writing should guide people through an experience and should be clear, concise, and contextually appropriate.
- Plain language reduces user effort and improves accessibility.
- Error messages must be visible, constructive, respectful, and recovery-oriented.
- Interface copy should use everyday words, explain unusual terms, and avoid ambiguous abbreviations.
- Product voice should be helpful and human, without becoming excessive or distracting.
- Complex text should have a simpler version or supplemental explanation.
