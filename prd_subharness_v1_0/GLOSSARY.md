# 术语表

| 英文 | 中文 | 通俗解释 |
|---|---|---|
| Orchestrator | 总控 / 编排器 | 负责分派任务，不直接生产事实。 |
| Sub-Harness | 子 Harness | 只负责一个领域的小型控制系统。 |
| Projection | 投影 | 从结构化事实生成给人看的文档。 |
| Change Request | 变更请求 | 用户写的自然语言更新。 |
| Change Ingest | 变更摄取 | 把自然语言拆成可处理的小变更。 |
| Patch Contract | 补丁契约 | 本轮能改什么、不能改什么。 |
| Impact Analysis | 影响分析 | 这次变更影响哪些需求、页面、指标、文档。 |
| Partial Rerun Plan | 局部重跑计划 | 只重跑受影响的子 harness。 |
| Tombstone | 删除墓碑 | 删除内容的原因、决策和影响记录。 |
| C-EARS | 中文受控需求句式 | 用稳定句式写需求。 |
| Fit Criteria | 可测规格 | 把“快、稳定、友好”变成可验证指标。 |
